# الفَلَك — أدوات فلكية عربية

موقع شخصي بخادم حيّ: يحسب **أي يوم وأي مكان لحظيًا**، بلا توليد مسبق ولا تشغيل خادم على جهازك.

المواقع ظاهرية (geocentric apparent) على المنطقة البروجية الاستوائية، بمكتبة Swiss Ephemeris —
وهي المصدر نفسه الذي تبني عليه المواقع الاحترافية.

## ما فيه

| الصفحة | ما تفعله |
|---|---|
| الرئيسة | مواقع الكواكب الآن وطور القمر |
| النشرة اليومية | برج القمر ومنازله، الزوايا بأوقاتها، خلو المسار، الأخبار الصحية — لأي يوم ومدينة، مع زر نسخ |
| خريطة الميلاد | العجلة الدائرية، ١٤ جِرمًا، الكرامات الخمس والأَلْمُطَن، ١٨ سهمًا، الأشكال الزاوية، النجوم الثابتة، ثمانية أنظمة بيوت، وقراءة عربية كاملة |
| مواقع الكواكب | جدول لأي لحظة مع السرعة والرجوع |
| تعلّم | ٣٥ مصطلحًا مشروحًا، ودروس في قراءة الخريطة |

### ما يميّزه عن المواقع العالمية

- **الكرامات الخمس والأَلْمُطَن** — البيت والشرف والمثلثة والحدّ والوجه بدرجات القوّة،
  وحساب أقوى كوكب في الخريطة على طريقة ابن أبي الرجال. لا يقدّمه Astrotheme أصلًا.
- **السهام العربية** — ثمانية عشر سهمًا من «التفهيم» للبيروني، بصيغها الليلية والنهارية.
- **المنازل القمرية الثماني والعشرون** — في العجلة وفي النشرة، وهي أصل علم الاختيارات.
- **النجوم الثابتة بأسمائها العربية** — الدبران وقلب الأسد والسماك، وأسماؤها في مراجع
  العالم كلها عربيّة الأصل.
- **نظام القبّاني** — بيوت أبي الصقر القبيصي التي عمل بها منجّمو بغداد.
- **التوقيت التاريخي مع تحذيرات صريحة** — يكشف الساعة الملتبسة والمعدومة، ويحسب
  التوقيت الشمسي المحلّي لما قبل ١٩٠٠.

## التشغيل على جهازك

```bash
pip install -r requirements.txt
python api/index.py          # http://localhost:8000
```

الملف نفسه يعمل خادمًا محليًا وعلى Vercel بلا تغيير.

## النشر على Vercel — خطوة بخطوة

1. **ارفع المشروع إلى GitHub**

   ```bash
   cd falak-web
   git init -b main
   git add .
   git commit -m "الفَلَك — المرحلة الأولى"
   git remote add origin https://github.com/<اسم-حسابك>/falak-web.git
   git push -u origin main
   ```

2. **اربطه بـ Vercel**: ادخل [vercel.com/new](https://vercel.com/new)، سجّل دخولك بحساب GitHub،
   اختر المستودع `falak-web`، ثم `Deploy`. لا تغيّر أي إعداد — `vercel.json` يضبط كل شيء.

3. خلال دقيقة يصبح الموقع على `https://falak-web-<شيء>.vercel.app`.

الخطة المجانية (Hobby) تكفي تمامًا لموقع شخصي.

### بديل بلا GitHub

```bash
npm i -g vercel
cd falak-web
vercel          # معاينة
vercel --prod   # نشر نهائي
```

## المعاينة بلا خادم

`preview/index.html` نسخة تعمل بنقرة مزدوجة، فيها ردود محفوظة مسبقًا لأيام قليلة.
للتحديث: `python tools/make_preview.py`

## واجهة الخادم

```
GET /api/health
GET /api/atlas?q=دمشق
GET /api/glossary
GET /api/ephemeris?date=2026-07-28&time=12:00&tz=Asia/Damascus
GET /api/bulletin?date=2026-07-28&city=دمشق&voice=today|tomorrow&shift=0|1
GET /api/chart?date=1990-05-17&time=08:30&city=حلب&system=…&compare=…&minor=1
```

أنظمة البيوت المتاحة: `whole` `alcabitius` `placidus` `koch` `regiomontanus`
`campanus` `porphyry` `equal`.

بدل `city` يمكن إرسال `lat` و `lon` و `tz` مباشرة لأي مكان في الأرض.

```
falak/patterns.py    الأشكال الزاوية: المثلّث الكبير، الصليب، الإصبع…
falak/stars.py       ٣٨ نجمًا ثابتًا بأسمائها العربية ودلالاتها
falak/timezone.py    التوقيت التاريخي والتحذيرات والتوقيت الشمسي المحلّي
falak/interpret.py   نصوص القراءة ومعجم المصطلحات — عدّلها كما تشاء
falak/atlas.py       ٢٩٤ مدينة محليًّا + احتياط عالمي عبر Open-Meteo

falak/bulletin.py    صياغة نصّ النشرة
assets/wheel.js      رسم العجلة الدائرية
index / bulletin / chart / ephemeris / learn .html   الواجهة
```
